# Bilresa IKEA button

pulsing yellow/orange means in general binding mode.

To get it to (re)join zigbee network:

Factory reset: knop ~10 sec ingedrukt
rood → daarna langzaam geel = OK
Wacht 5–10 sec (belangrijk, anders negeert hij input)

4× drukken
→ LED moet sneller knipperen
→ dit is Touchlink fase

Direct daarna 8× drukken
→ LED kan zelfs uit gaan
→ nu zit hij in Zigbee mode

Nu kan hij joinen.

Sommigen zeggen: Start daarna pas “add device” op je coordinator
